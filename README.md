# 🔐 PrivateChats – Flutter UI Template

A **privacy-focused Flutter UI template** showcasing a modern app interface with **Moments**, **Spotlight**, and clean, reusable components.  
This project is **UI-only** and is meant for learning, customization, and rapid prototyping.

> ⚠️ **Note:** This is **not a real chat application**.  
> No backend, no authentication, no real messaging — just UI.

---

## ✨ Overview

**PrivateChats** is a Flutter-based UI template inspired by privacy-first communication apps.  
It focuses on layout, structure, and user experience rather than functionality.

Perfect for:
- Learning Flutter UI patterns
- Practicing layout & navigation
- Building your own app on top of a clean UI base

---

## 🧩 Key Screens & Components

- 📱 **Modern App Layout**
- 🗨️ **Chats UI (Template)**
- 🌟 **Moments Section** (personal updates UI)
- ✨ **Spotlight Section** (public/featured UI)
- 👤 **Profile / About Me Page**
- 🔒 **Privacy-themed dialogs & alerts**
- 🧱 **Reusable Widgets & Cards**
- 🌙 **Dark/Light Theme ready**

---

## 🛠️ Tech Stack

- **Flutter**
- **Dart**

## 🚀 Run Locally

Follow these steps to run the project on your machine:

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Subhamaym06/PrivateChats.git
```

### 2️⃣ Navigate to the project folder
```bash
cd PrivateChats
```

### 3️⃣ Get dependencies
```bash
flutter pub get
```

### 4️⃣ Run the app
```bash
flutter run
```

## 📱 Obtain APK

Run the following command in your terminal:
```bash
flutter build apk
```
The APK will be generated at:
`build/app/outputs/flutter-apk/app-release.apk`

>💡 Make sure Flutter is installed and properly set up. Check with:
```bash
flutter doctor
```
